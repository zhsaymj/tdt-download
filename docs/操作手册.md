# 天地图下载处理工具 · 操作手册

面向使用者。本工具用于在地图上框选范围，批量下载天地图影像 / 全国地形（DEM），并自动处理成带坐标的 GeoTIFF、TMS/OSM 瓦片、Cesium 地形切片等成果。

---

## 一、启动与访问

### 打包版（推荐，给同事用）

1. 进入 `天地图下载工具` 文件夹，双击 **`天地图下载工具.exe`**。
2. 会弹出一个黑色控制台窗口（显示运行日志），并自动打开浏览器访问 `http://127.0.0.1:8000`。
3. 浏览器没自动打开时，手动访问 `http://127.0.0.1:8000` 即可。
4. **关闭那个黑色控制台窗口 = 停止服务**。使用期间不要关它，最小化即可。

> 数据、配置、成果都存在 exe 同级目录下的 `data/`、`config.yaml`、`output/` 里。给同事拷贝时，把整个 `天地图下载工具` 文件夹一起拷。

### 界面布局

- **左侧**：① 选择范围 ② 下载参数，顶部有「密钥管理」按钮。
- **中间**：地图（点任务后下方显示任务详情）。
- **右侧**：任务队列，顶部有「运行日志」按钮。

> 📷 **截图占位【图 1 · 主界面全貌】**：拍整个浏览器窗口，能看到左侧参数面板、中间地图、右侧任务队列三栏，用于让读者建立整体印象。

## 二、首次使用：配置天地图密钥

下载**影像**必须先配密钥（下载**地形**不需要密钥，走全球免费数据源）。

1. 点左上角 **「密钥管理」**。
2. 填入你在[天地图控制台](https://console.tianditu.gov.cn/api/key)申请的密钥，可加备注名，设置每日请求上限（默认 150 万）。
3. 「添加」后即生效。

> 📷 **截图占位【图 2 · 密钥管理】**：打开「密钥管理」弹窗，拍新增表单 + 已有密钥列表（含启用开关、已用/上限），标注「多个密钥自动轮询」。

说明：
- 支持**添加多个密钥**，系统会轮流使用、分摊配额；某个配额用尽会自动切换下一个。
- 可随时**启用 / 停用**某个密钥，或就地修改备注和上限。
- 密钥有每日调用配额，**大范围高级别瓦片量极大**，请按需下载。

## 三、操作流程总览

> 选范围 → 设参数 → 加入队列 → 看进度 → 取成果 / 预览

### 第 1 步：选择下载范围（左侧「1. 选择范围」）

四种方式任选其一：

| 方式 | 说明 |
|------|------|
| **行政区选择** | 下拉选 省 / 市 / 县，自动加载该行政区边界作为范围 |
| **绘制矩形** | 点按钮后在地图上拖出矩形 |
| **绘制多边形** | 点按钮后在地图上逐点单击，双击结束 |
| **导入矢量** | 导入 GeoJSON / KML / Shapefile（.zip 或同时选 .shp/.dbf/.shx，建议附 .prj） |

辅助操作：
- **编辑**：拖内部平移、拖角点缩放；多边形可点边中点加点、右键顶点删点。
- **清除**：清空当前范围。
- 面板底部实时显示范围的经纬度四至。

> 📷 **截图占位【图 3 · 选择范围】**：拍左侧「1. 选择范围」面板 + 地图上已框出的一个矩形/多边形范围，标注四种选范围方式的按钮位置。

### 第 2 步：设置下载参数（左侧「2. 下载参数」）

顶部有 **「影像」** 和 **「地形（DEM）」** 两个标签页，分别配置，详见下文第四、五节。

底部有 **「同时下载地形 / 同时下载影像」** 勾选框：勾上后，一次提交会**同时建两个任务**（影像 + 地形各一个），互相独立。

> 📷 **截图占位【图 4 · 下载参数面板】**：拍左侧「2. 下载参数」面板，能看到「影像 / 地形（DEM）」两个标签页、底部「同时下载」勾选框和「加入下载队列」按钮。

### 第 3 步：加入下载队列

- 确认级别、看清预估下载量后，点 **「加入下载队列」**。
- 任务出现在右侧队列，自动开始。

### 第 4 步：看进度

右侧任务卡片显示：
- 级别范围、已下载 / 总瓦片数、**预估下载 ~X**（仅原始瓦片下载量，非成果大小）。
- **分阶段进度条**：下载 → 合并 → 切片，每个阶段独立显示百分比、状态、剩余时间。
- 底部「预计总剩余」为整体估算（未开始阶段是粗估，实际常更快）。

> 📷 **截图占位【图 5 · 任务进度】**：拍右侧一个进行中的任务卡片，能看到分阶段进度条和「预计总剩余」。

### 第 5 步：取成果 / 预览

- 任务完成后，点卡片上的 **「预览」** 在 3D 地球上查看。
- 成果文件在 **导出目录**（任务详情里可看到完整路径，通常是 `output/任务名/`）。

## 四、影像下载详解（「影像」标签页）

> 📷 **截图占位【图 6：影像参数标签页】**：影像标签页全貌，包含数据类型下拉、级别勾选列表（含每级瓦片数/大小）、导出格式、注记与坐标系、底部预估行。

| 参数 | 说明 |
|------|------|
| **任务名称** | 决定输出目录名和成果文件名前缀 |
| **数据类型** | 天地图影像 / 天地图矢量底图 / 天地图地形晕渲 |
| **下载级别** | 勾选要下载的层级（1–18），可全选。**每升 1 级瓦片数约 ×4**，逐级列出该级瓦片数与大小 |
| **导出格式** | 可多选：见下表 |
| **叠加路网注记** | 勾选后同步下载路网/地名注记，烘焙进成果（瓦片数翻倍） |
| **输出坐标系** | GeoTIFF 的坐标系，支持 EPSG:4326、CGCS2000（4547/4545 等）等 |
| **裁剪到边界** | 用矢量面/多边形范围时可勾，把成果裁剪到几何边界，边界外透明 |

**导出格式说明：**

| 格式 | 产物 | 用途 |
|------|------|------|
| **带坐标 GeoTIFF** | 每级一张 `.tif` | QGIS/ArcGIS 里叠加分析 |
| **TMS 瓦片** | `tms/` 目录 + xml | 标准 TMS 瓦片服务（EPSG:4326） |
| **OSM 瓦片** | `osm/` 目录 | Web 墨卡托 XYZ 瓦片（在线地图常用） |

> GeoTIFF 可改选 **COG / PNG / JPEG**，瓦片可打包成 **MBTiles** 单文件。
> 勾选格式后下方会出现「文件格式」下拉，详见
> [更新说明 · 导出格式扩展](更新说明-导出格式扩展.md)。

> **提示**：勾选 OSM 时会自动带上 GeoTIFF——因为 OSM 切片需要最高级拼接图作源，且会直接复用合并结果，不重复拼接。TMS 不需要 GeoTIFF（直接由缓存瓦片映射）。
>
> 若输出坐标系选了非 4326（如 CGCS2000 某带），会同时生成一份 4326 主文件（`名称_z级别.tif`）和一份对应投影的成果（`名称_z级别_带号.tif`）。

> 🔧 **进阶（技术细节）**：
> - OSM 切片用 WarpedVRT 窗口读 + 多线程（按 CPU 核数并行），对大源图（5GB+）内存占用低、速度快。
> - 大范围成果可能超 4GB，输出 GeoTIFF 已启用 BIGTIFF，不会因超限失败。
> - OSM 会复用 GeoTIFF 合并结果作源;裁剪时复用裁剪前的未裁剪源，避免边界暗边。

## 五、地形下载详解（「地形（DEM）」标签页）

> 📷 **截图占位【图 7：地形参数标签页】**：地形标签页全貌，重点拍到级别列表里「该范围最高 N 级」提示、超限级别置灰、导出格式(高程/LERC/Cesium 地形)。

数据源为 **Esri Terrain3D**（全球免费、无需密钥），下载的是**真实海拔高程**。

| 参数 | 说明 |
|------|------|
| **下载级别** | 0–16。选范围后系统自动**探测该范围最高可用级别**，超出的级别置灰（无数据）。中国多数区域约 13–15 级 |
| **导出格式** | 见下表 |
| **输出坐标系** | 高程 GeoTIFF 的坐标系 |

**导出格式说明：**

| 格式 | 产物 | 用途 |
|------|------|------|
| **高程 GeoTIFF（真实海拔）** | 每级一张 `名称_dem_z级别.tif` | QGIS 里出坡度、剖面 |
| **TMS 瓦片（晕渲可视化）** | `tms/` 目录 | 把地形起伏当底图叠加看（EPSG:4326） |
| **OSM 瓦片（晕渲可视化）** | `osm/` 目录 | 同上，Web 墨卡托 XYZ |
| **保留原始 LERC 瓦片** | `tiles/` 目录 | 保留下载的原始瓦片包 |
| **Cesium 地形切片** | `terrain/` 目录 + layer.json | CesiumJS 三维地形（quantized-mesh-1.0） |
| **等高线（矢量）** | `名称_contour.geojson` 等 | 规划、水利交付；带「高程」属性，等高距可设 |

同时还可生成 **晕渲图（hillshade）**，用于地形阴影效果展示。

> 高程 GeoTIFF 可改选 **COG / ASCII Grid / XYZ / PNG**，瓦片可打包成 **MBTiles**，
> 等高线可选 **GeoJSON / GPKG / Shapefile**。见 [更新说明 · 导出格式扩展](更新说明-导出格式扩展.md)。

> **关于 Cesium 地形切片的级别**：只用所选的**最高层级**作高程源，Cesium 会自动从 0 级逐级细化。如果只要地形切片，选一个最高层级即可，多选低层级只增加下载量、不提升精度。

## 六、任务管理

> 📷 **截图占位【图 8：任务卡片】**：一个进行中的任务卡片，拍到分阶段进度条(下载/合并/切片各一行、百分比、剩余时间)、底部预计总剩余、底部操作按钮。最好再拍一张某阶段失败、显示「续切 / 删除并重试」两个按钮的状态。

右侧任务卡片上的操作按钮（随任务状态显示）：

| 按钮 | 作用 |
|------|------|
| **预览** | 3D 地球查看成果（任一切片阶段完成即可用） |
| **暂停** | 暂停进行中的任务；已下载/已切的成果保留 |
| **开始** | 继续暂停/失败的任务，从断点**续传/续切**，不重复劳动 |
| **重新下载** | 改参数（级别/格式/坐标系等）后重新跑，会清空旧成果 |
| **删除** | 删除任务（可选是否连同成果目录一起删） |

**某个阶段失败时**，该阶段会显示两个按钮：

| 按钮 | 行为 |
|------|------|
| **续切** | 保留已切好的瓦片，只补没切完的部分（推荐，快） |
| **删除并重试** | 清空该阶段旧产出，从头彻底重切 |

### 断点续传 / 续切

- 下载中途暂停再开始：已下载的瓦片有缓存，会跳过、只下没下完的。
- 切片（TMS/OSM/地形）中途暂停再开始：已切好的瓦片会跳过，从断点接着切。
- 所以任务卡住或想歇会儿，直接暂停 / 关程序都不会丢进度，重开继续即可。

### 运行日志

右上角 **「运行日志」** 打开实时日志抽屉：
- 按级别着色（蓝=信息、黄=警告、红=错误）。
- 切片过程中每几秒刷新一条进度明细（切到第几张、百分比、剩余时间、速率）。
- 判断任务是「在正常跑」还是「真卡住」：只要日志里的进度数字在涨，就是在正常跑。
- 历史日志也存在 `data/logs/app.log`，可事后翻查。

## 八、成果文件说明

打开任务的导出目录（默认 `output/任务名/`），可能包含：

```
任务名_z12.tif            影像/高程 GeoTIFF（EPSG:4326 主文件，每级一张）
任务名_z12_4547.tif       对应投影版（选了非 4326 坐标系时才有）
任务名_dem_z12.tif        高程 GeoTIFF（地形任务）
任务名_hillshade_z12.tif  晕渲图（勾选时）
tms/                      TMS 瓦片包（含 tilemapresource.xml）
osm/                      OSM 瓦片包（{z}/{x}/{y}.png）
terrain/                  Cesium 地形切片（含 layer.json）
tiles/                    原始 LERC 瓦片（地形，勾选保留时）
任务名_contour.geojson    等高线（地形，勾选时；可选 .gpkg / .shp）
任务名_buildings.geojson  建筑轮廓（三维建筑；可选 .gpkg / .shp）
3dtiles/                  三维建筑白模（b3dm + tileset.json）
任务名_tms.mbtiles        TMS 瓦片单文件包（选 MBTiles 时，替代 tms/ 目录）
任务名_osm.mbtiles        OSM 瓦片单文件包（选 MBTiles 时，替代 osm/ 目录）
metadata.json             任务信息与成果清单
```

选了非默认「文件格式」时扩展名随之变化（如 COG 仍是 `.tif`、ASCII Grid 为 `.asc`
+ `.prj`、PNG 为 `.png` + `.wld`）。Shapefile 会有 5 个文件（`.shp/.shx/.dbf/.prj/.cpg`），
**拷贝时必须全部带走**，少一个 `.prj` 就丢坐标系。

## 九、常见问题

**Q：预估大小和实际成果大小对不上？**
预估的是**原始瓦片下载量**（下载多少数据），不是成果文件大小。GeoTIFF 会压缩、OSM/TMS 会重新编码，成果大小和下载量本就是两回事。

**Q：任务好像卡住不动了？**
先看「运行日志」。大范围高级别的 OSM 切片、地形切片本身就很慢（可能几十分钟到几小时），只要日志进度在涨就是正常。真卡住（日志长时间不动）可暂停后重新开始。

**Q：下载很慢 / 想更快？**
影像下载并发数可在 `config.yaml` 的 `download.concurrency` 调高（网络够快时）。切片已用多线程按 CPU 核数并行。

**Q：级别越高越慢是正常的吗？**
是。每升 1 级瓦片数约翻 4 倍。建议先小范围 + 中等级别（如 10–14）试跑，确认效果再下大范围/高级别。

**Q：密钥配额不够用？**
在「密钥管理」里添加多个密钥，系统会自动轮流使用、分摊配额。

**Q：换电脑 / 分发给同事？**
拷贝整个 `天地图下载工具` 文件夹即可。密钥、缓存、成果都在文件夹内。同事那边同样双击 exe 运行。

## 十、注意事项

- 下载影像需遵守天地图服务条款，密钥有每日调用配额，请按需下载。
