## 动手前的事实核查(这是选型的依据)

磁盘实况:`data/logs/app.log` **3.2 MB**、内容跨 **2026-07-24 ~ 2026-09-29(26 个使用日)**、32,479 行、**零个备份文件**。

逐日统计(从真实文件量出):

| 指标 | 值 |
|---|---|
| 平均单日 | 100 KB |
| 最大单日(2026-09-28) | 686 KB |
| 5 MB 阈值下最大单日占比 | 13.4% |

**结论:问题不是"单个文件写太大",而是"一个文件跨了两个月"。** 原有的 `RotatingFileHandler(5MB×3)` 在当前强度下要 26 天才轮转一次,等于没轮。

### 隔离验证:现有 `app.log` 不被破坏

在临时文件上预置"历史内容"再挂新 handler 写入:

| 检查 | 结果 |
|---|---|
| 原有内容是否保留 | **是** |
| 新日志是否追加 | **是** |
| 行数 前/后 | 2 / 3 |

`TimedRotatingFileHandler` 以追加方式打开已存在的文件,不会截断。所以那份跨两个月的 `app.log` 会原样保留,直到首次轮转时被改名为 `app.log.<轮转日>`。

## 手工验证(2026-09-29 11:42~11:49 实测完成)

**为什么必须重启**:`logs.py` 的改动在 10:33 落地,而当时运行的服务是 09:15:55
启动的 —— 进程在启动时就加载了旧 `logs.py`,不会热加载。
(顺带核实:需求33 的级别修复 08:58、需求34 的前端 09:13,都**早于** 09:15:55,
所以只有需求35 需要重启,不是全部都要。)

顺序是「**停服务 → 触发轮转 → 起服务**」—— 服务运行时 `app.log` 被占用,
Windows 下改名会抛 `PermissionError [WinError 32]`。

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 停服务后看 `data/logs/app.log` | 3,337,811 字节 / 33,315 行,首行 `2026-07-24 09:41:19` |
| 2 | 触发一次轮转 | 生成 `app.log.2026-09-29` = **3,337,811 字节**(与轮转前逐字节一致);`app.log` 重建为 0 字节 |
| 3 | 重启服务后看 `app.log` | 388 字节,是重启后的启动日志(见下) |
| 4 | `/api/logs`(面板数据源) | 返回 3 条、UTF-8 正确、时间戳是重启后的 |
| 5 | 前端 dist 含新文案 | `dist/assets/index-EMTskXmp.js` 里有「按日期分文件」 |

> 轮转文件名是**当天**日期,不是"昨日":标准库按刚过去的那个零点算
> (`rolloverAt - interval`),不是按"上一次轮转时刻"。

### 两个现场发现

1. **旧服务的 worker 成了孤儿进程**。`taskkill` 只杀主进程(21008),它的两个
   multiprocessing 子进程(28300 / 63596,09:15:57 启动)一直活到 11:48 才被
   清掉 —— Windows 下子进程不随父进程退出。下次重启前建议先确认没有残留
   `python` 进程,否则会攒下一堆空转 worker。
2. **`data/logs/app.log.probe`(1 字节,内容 `x`)来源不明**,全仓 grep 无引用,
   不是本次改动产生的。已留在原地未动。

## 执行期发现并修正的三处(原计划的问题)

1. **护栏不该操作真实的 `data/logs/app.log`**。原计划用它验证解耦,实测发现:
   ① 运行中的服务进程持有该文件句柄,Windows 下改名抛 `PermissionError [WinError 32]`;
   ② 测试会往用户真实日志写标记、还会轮转它。
   **改为临时文件 + 临时 handler** —— 验的仍是"面板不依赖文件内容"。
   (另:`shutil.move` 的降级路径会先复制成功、再 unlink 失败,留下残留副本,实测确认。)

2. **标准库把 `when` 存成大写**(`'MIDNIGHT'`),原断言 `== 'midnight'` 必然失败。
   改为比较 `.lower()`。

3. **补一条"轮转确实发生"的前置断言**。原计划只断言"轮转后面板仍可见" ——
   若 `doRollover()` 空转,这条会**真空通过**,测不到任何东西。
   现已先断言轮转产物存在(列出目录内容作为失败信息)。
