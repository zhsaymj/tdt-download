# 3D Tiles 分层优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 降低 OSGB 转换结果在 Cesium 远景中的主清单解析成本和过度细化。

**Architecture:** 保留原转换器与顶层粗模型；转换完成后由 Python 优化器把 Tile 子树外置、修正误差并清理失效引用。服务扫描跳过外部清单。

**Tech Stack:** Python 3.11、unittest、3D Tiles 1.0、Cesium。
