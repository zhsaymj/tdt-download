# 天地图双网格导出 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 天地图任务同时勾 tms+osm 时按各自原生网格下两套瓦片,使两个格式都无损。

**Architecture:**
- D1: `download_grids_of(provider, export_formats)` 纯函数,从 provider+格式推导要下的网格
- D2: `TiandituProvider.key` 带上 `_{matrix_set}`(如 `tianditu_img_c`);启动时把旧缓存目录
  rename 成新名字(迁移现有约 18 万张瓦片)
- D3: 下载阶段对每个网格各用一个 provider 实例、各下一个 `range_for_bbox`
- D4: `_osm_source_for_level` 在有 mercator 缓存时拼 3857 源,使 `export_osm` 的
  WarpedVRT 退化为 3857→3857 空操作、零重投影

**Tech Stack:** Python 3.11、Vue3、GDAL、rasterio

**Spec:** `docs/superpowers/specs/2026-09-29-天地图双网格导出-design.md`

## Global Constraints

1. 不改变任何用户可见的默认行为(只添加新的下载网格,不改已有格式/内容)
2. 缓存键必须带网格网格(e.g. `tianditu_img_c` vs `tianditu_img_w`) —— 这是本计划的**硬约束**,
   否则 `_c` 与 `_w` 两种行号不同的瓦片会互相覆盖、静默错乱
3. 天地图 key 迁移映射:影像/矢量/地形 → `_c`;注记(cia/cva/cta) → `_w`
4. 非天地图 provider 的 key 不变
5. Cesium 预览侧不涉及改动(已确认)

## 关于本计划的完备度(执行前必读)

```python
# backend/core/cache_migrate.py
"""缓存目录由 key 改 key_{grid} 的一次性迁移。

设计文档 D2:缓存键必须带网格,否则 _c 与 _w 两种行号不同的瓦片会互相覆盖。
详情见 `docs/superpowers/specs/2026-09-29-天地图双网格导出-design.md`。

迁移映射:
  影像/矢量/地形(key) → _c :下 c 网格
  注记(key)          → _w :下 w 网格(现有注记缓存全是 _w)
  非天地图 key        → 不在列表中,不迁移
"""
from __future__ import annotations

from pathlib import Path

#: key → 网格后缀(迁移目标)。注记类现有缓存全是 _w,不能按 _c 处理。
_GRID_MAP = {
    "tianditu_img": "c",
    "tianditu_vec": "c",
    "tianditu_ter": "c",
    "tianditu_cia": "w",
    "tianditu_cva": "w",
    "tianditu_cta": "w",
}


def migrate_cache_grids(tiles_root: Path) -> int:
    """把 tiles_root 下已知的 key 目录从 `{key}/` 改名为 `{key}_{grid}/`。

    返回实际迁移了的 key 数(0 = 无迁移必要)。
    迁移是原子的:os.rename 在一个盘上瞬间完成。
    安全守护:目标已存在时跳过(不覆盖);源不存在时也跳过。
    """
    count = 0
    for key, grid in _GRID_MAP.items():
        src = tiles_root / key
        if not src.is_dir():
            continue
        dst = tiles_root / f"{key}_{grid}"
        if dst.exists():
            continue
        src.rename(dst)
        count += 1
    return count
```

# formats.py 中,在 PROVIDER_GRID 同类定义附近添加

#: 各导出格式需要的网格(不列出者不限,用源默认网格)。
_FORMAT_GRID: dict[str, str] = {
    "osm": GEO_MERCATOR,
    "tms": GEO_GEODETIC,
}

#: 数据源原生提供哪些网格(未登记者只有自己的默认网格)。
PROVIDER_GRIDS: dict[str, tuple[str, ...]] = {
    "tianditu_img": (GEO_GEODETIC, GEO_MERCATOR),
    "tianditu_vec": (GEO_GEODETIC, GEO_MERCATOR),
    "tianditu_ter": (GEO_GEODETIC, GEO_MERCATOR),
    # 注记跟随源,不在这里登记(它们不直接用于下载)
}


def download_grids_of(provider: str, export_formats: list[str]) -> list[str]:
    """返回该任务实际要下载的网格(升序稳定顺序,用于下载管线循环)。

    规则:从源默认网格出发,对每个请求格式判断是否需要另一种网格;
    只有源确实提供那种网格时才加入。
    """
    required = set([grid_of(provider)])  # 默认网格总是要的
    avail = PROVIDER_GRIDS.get(provider, ())
    for fmt in export_formats:
        need = _FORMAT_GRID.get(fmt)
        if need is not None and need in avail:
            required.add(need)
    return sorted(required, key=lambda g: (g != GEO_GEODETIC, g))
```

def _range_fn_for(provider: str, grid: str | None = None) -> Callable:
    """可按网格显式指定;不传或 None 时回退到按 provider 推断(向后兼容)。"""
    if grid is not None:
        return mercator_range_for_bbox if grid == GEO_MERCATOR else range_for_bbox
    # 按 provider 推断(与原来一样)
    _grid = grid_of(provider)
    return mercator_range_for_bbox if _grid == GEO_MERCATOR else range_for_bbox
```
